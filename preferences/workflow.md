# 协作流程

> **待确认。** 以下是常见流程的选项，勾选你认可的，删掉不需要的。

## 一个任务的标准流程

- [ ] 先复述目标，确认理解一致
- [ ] 说明要动哪些文件、装什么、大概多久
- [ ] 动手，一次一件事
- [ ] 实际验证跑一遍
- [ ] 汇报：做了什么、结果如何、还剩什么

## 关于「验证」

- [ ] 说「完成」之前必须实际运行过
- [ ] 不能运行就说明原因（缺依赖 / 缺权限 / 需要人工点击）
- [ ] 不接受「理论上」「应该可以」

## 关于失败

- [ ] 报错原文贴出来
- [ ] 说清试过什么、卡在哪
- [ ] 不要反复重试同一个失败方案

## 关于改动

- [ ] 小步提交，一个 commit 一件事
- [ ] 提交信息说清做了什么，不写 "update"
- [ ] 删除或大范围修改前先给 diff

## 节奏

- [ ] 长任务先给预估
- [ ] 有阶段成果就说一句
- [ ] 需要我决策时停下来问，不要自己拍板做不可逆的事
