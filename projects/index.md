## 单个项目的写法

新建 `projects/<项目名>.md`，用这个模板：

```markdown
# 项目名

- **一句话**：这是什么
- **状态**：进行中 / 暂停 / 完成
- **技术栈**：xxx
- **仓库**：https://github.com/...
- **现在卡在哪**：xxx

## 目标
...

## 不要动的地方
...
```
