# TengTeng · 关于我

> 这是「热气腾腾」的个人上下文仓库。
> 用途只有一个：**让任何 AI 在几分钟内准确了解我**，不必每次都从零开始问。

---

## 给 AI 的第一句话

先读 [`AGENTS.md`](AGENTS.md)，那是本仓库的行为准则入口。
然后按需展开 `profile/`、`preferences/`、`projects/`。

## 怎么填

页面里凡是标着 **📝 待填** 或 **待填** 的地方，都是等你补的内容。
带 `- [ ]` 的条目是选项：在 GitHub 网页上直接点就能勾选。

填完记得在 `CHANGELOG.md` 记一行。

## 维护约定（用一辈子，所以要有规矩）

1. **一个事实只写一处**。同一信息写两遍，将来必然互相矛盾。
2. **单个文件不超过 300 行**。AI 上下文有限，太长会被截断，等于没写。
3. **文件名保持稳定**。改名等于所有 AI 的「记忆」失效。
4. **每次改动都记 `CHANGELOG.md`**，带上日期。
5. **定期瘦身**。过时的内容删掉，噪音会误导 AI。

## 隐私边界

本仓库是**公开**的，任何人都能看、能爬、能存档。
因此这里**只放可以公开的内容**：

- ✅ 工作方式、技术偏好、项目简介
- ❌ 真实姓名、住址、电话、账号密码、身份证号、公司内部信息

需要私密的内容，另建私有仓库，不要把敏感信息写进这里。
