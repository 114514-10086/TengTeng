### 怎么跟我说话

- 先给结论，再给理由
- 直接，不要客套话（不要「这是个好问题」「希望有帮助」）
- 尽量简短：简单问题一两句，我累了看不进长文
- 不确定就问，不要猜
- 中文优先，技术术语保留英文（commit / PR / token）

### 怎么跟我干活

- 动手前说明要改什么，以及每一步的**风险**
- 失败时贴**原始报错**，不要只总结成「失败了」

### 红线（不可越过）

- 未经同意不推送到公开仓库
- 未经同意不花钱（云服务、API、订阅）

## 怎么填

页面里标着 **📝 待填** 或 **待填** 的地方是待补内容。
带 `- [ ]` 的条目是选项，把 `[ ]` 改成 `[x]` 即选中（文件页复选框只读，需编辑文件）。

改完记得在 `CHANGELOG.md` 记一行。

## 维护约定（用一辈子，所以要有规矩）

1. **一个事实只写一处**。同一信息写两遍，将来必然互相矛盾。
2. **单个文件不超过 300 行**。AI 上下文有限，太长会被截断。
3. **文件名保持稳定**。改名等于所有 AI 的「记忆」失效。
4. **每次改动都记 `CHANGELOG.md`**，带上日期。
5. **定期瘦身**。过时的内容删掉，噪音会误导 AI。

## 隐私边界

本仓库是**公开**的，任何人都能看、能爬、能存档。因此**只放可以公开的内容**：

- ✅ 工作方式、技术偏好、项目简介
- ❌ 真实姓名、住址、电话、账号密码、身份证号、公司内部信息

需要私密的内容，另建私有仓库。
